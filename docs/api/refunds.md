# Refunds & Inquiry Tracking

The Refund API returns funds to the customer after order return or cancellation.

- **Endpoints:**
  - Request Refund: `POST /refunds?type={type}`
  - Track Refund Status: `POST /refunds/{inquiryId}?type={type}`

---

## 1. Requesting a Refund

A refund requires:
- `saleTrackingCode`: Original purchase tracking code.
- `amount`: Amount in Rials (supports full or partial refund).
- `providerId`: A unique refund ID generated by the merchant (for idempotency and tracking).

```php
use Eamirgh\Digipay\Facades\Digipay;
use Eamirgh\Digipay\DTO\RefundRequest;

// Direct invocation
$refund = Digipay::refund(
    saleTrackingCodeOrRequest: '10357963991735727353649',
    amount: 500000, // 500,000 Rials
    providerId: 'REFUND_REQ_2026_001'
);

if ($refund->isSuccessful()) {
    $refundTrackingCode = $refund->trackingCode; // Digipay refund tracking code
}

// Or with DTO
$dto = new RefundRequest(
    saleTrackingCode: '10357963991735727353649',
    amount: 500000,
    providerId: 'REFUND_REQ_2026_001'
);

$refund = Digipay::refund($dto);
```

## 2. Tracking a Refund

Because banking inter-network settlement (Paya/Satna) or card refund can take time, merchants can track the settlement progress:

```php
use Eamirgh\Digipay\Facades\Digipay;

// Pass either your unique providerId or Digipay's refund trackingCode
$status = Digipay::trackRefund('REFUND_REQ_2026_001');

if ($status->isSuccessful()) {
    // Refund completed & transferred to user
    $dest = $status->destination;         // e.g. "603799******1234"
    $destType = $status->destinationType; // 0: PAN, 1: IBAN, 2: Wallet, 3: Credit
    $transferDate = $status->transferDate;
} elseif ($status->isPending()) {
    // In progress, retry inquiry later
} elseif ($status->isFailed()) {
    // Refund failed
}
```

---

## Status Reference

### TrackRefundResponse Status Codes
- `0`: **Success** - Transferred to customer.
- `1`: **Failure** - Refund failed.
- `2`: **Undetermined / In-Progress** - Waiting on banking network, retry later.

### Destination Types
- `0`: Masked Card PAN
- `1`: IBAN (Shaba)
- `2`: Digipay Wallet
- `3`: Credit Account
